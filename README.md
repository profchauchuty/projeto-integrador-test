# Gestão de Cantinas

## Objetivo
Desenvolver um aplicativo móvel voltado para gestão de cantinas.

## Objetivos Específicos
- Cadastro de Usuários
- Cadastro de Estoque
- Cadastro de Pedido
- Cadastro de Venda
- Gerar comprovante
